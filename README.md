# Black Pearl TV — APK Downloads

Public download repository for the **Black Pearl TV** Android TV client.

The application is a private home-cinema customization based on the Jellyfin Android TV client. This repository contains **compiled APK builds only** for easy installation on NVIDIA Shield, Fire TV / Fire TV Cube and compatible Android TV devices.

## Current build

**Black Pearl TV V1**

Stable direct-download path:

`https://raw.githubusercontent.com/uansmann/Black-pearl-tv-releases/main/BlackPearl-TV.apk`

This URL is intentionally kept stable so it can be entered once in Downloader on Android TV / Fire TV.

## Installation

1. Open **Downloader** on the TV device.
2. Enter the direct APK URL above.
3. Allow installation from unknown sources for Downloader if Android asks.
4. Install **Black Pearl**.
5. The app uses its own package ID and can be installed alongside the official Jellyfin Android TV app.
